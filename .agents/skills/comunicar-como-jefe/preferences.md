## texto-corto-por-defecto
- Regla: usar ~30 lineas como orientacion, no como objetivo ni limite; ajustar al detalle pedido o necesario para responder cada pregunta, explicar el resultado y comunicar evidencia y riesgos materiales. Lenguaje sencillo no implica respuesta ultracorta.
- Cuando aplica: cualquier respuesta consolidada de @orquestador o de un agente en fallback.
- Ejemplo: una auditoria profunda genera informe tecnico interno + resumen ejecutivo corto al final, no un tocho.
- Advertencia: recortar por longitud puede ocultar evidencia o riesgos; el contrato de claridad y transparencia manda sobre este default.
